# Спецификация форка Agora

## Фичи
A. Терминал: отдельный полноценный экран (PTY внутри выбранной песочницы, Ctrl+C, стрелки, Tab, цвета, прокрутка, несколько сессий; сессии модели видны в списке). Существующий Sandbox Management (менеджер пакетов) остаётся.
B. Дистрибутивы: Alpine (уже есть, по умолчанию), Debian, Ubuntu 24.04 LTS. Только arm64. Реестр дистрибутивов (манифест: id, URL, sha256, размер, архитектура, пакетный менеджер), скачивание при установке, не внутри APK. Текущие установки Alpine должны продолжить работать.
C. Долгие сессии: у shell-инструмента параметр persistent (по умолчанию false: как сейчас). persistent=true: сессия живёт между вызовами, возвращается session_id, можно читать новый вывод, слать ввод, завершать. Foreground service с уведомлением и кнопкой «Остановить всё».

## Решения
1. Менеджер дистрибутивов: отдельный экран «Дистрибутивы» из Sandbox Management, который работает с выбранным дистрибутивом. Для Debian/Ubuntu в v1 без экрана пакетов (пакеты через терминал).
2. Список пакетов брать из реальной базы пакетов, а не из собственного учёта.
3. Сессии завершаются: приложение убрано из недавних (onTaskRemoved), «Остановить всё», явное завершение пользователем или моделью, смерть процесса.
4. У каждого дистрибутива свой /home/agora (сохраняется при сбросе); обмен файлами через /mnt/shared.
5. Параметр distro у shell_exec и всех file_*; по умолчанию выбранный дистрибутив; сессия привязана к одному дистрибутиву.
6. Блокировка на дистрибутив вместо глобального мьютекса: одноразовые shell_exec, пакетные операции, upgrade, установка rootfs и сброс берут её; сессии и терминал не держат. Сброс сначала завершает сессии дистрибутива.
7. Подпись: своего секретного ключа нет; фиксированный публичный fork-debug.keystore в корне.

## Факты о коде (из разведки, проверять по коду)
- proot собирается build-proot.sh из thirdparty/proot (форк termux) и thirdparty/talloc: libproot_exec.so, libproot_loader.so, libtalloc.so, только arm64. JNI-библиотека agora_proot — заглушка, чтобы Android распаковал эти файлы.
- Alpine 3.21 minirootfs скачивается на устройстве, проверяется по SHA-256. Сброс удаляет rootfs, но сохраняет /home/agora.
- Инструменты: shell_exec, shell_list, file_* (file_* работают с rootfs напрямую, без proot).
- Каждая команда = отдельный процесс proot под глобальным мьютексом; stderr в stdout; лимит вывода ~1 MB; опрос завершения 25 мс; таймаут 1–~295 с; при таймауте SIGTERM, через 250 мс забирается остаток; --kill-on-exit всегда.
- PTY и терминала нет; Sandbox Management показывает только лог установки пакетов; отдельного foreground service для песочницы нет (есть общий сервис генерации типа dataSync).
- Песочница только во flavor fdroid (в play заглушка). targetSdk 36, minSdk 26 (ARCHITECTURE.md говорит 24 — расхождение). Debug-сборка под x86_64, proot только arm64: на устройстве проверять релизную fdroid-сборку.
- ProotSandboxManager.kt почти упёрся в лимит CI 999 строк.
- CI: unit-тесты, проверка размера файлов, тест Play-заглушки, сборка proot, assembleFdroidRelease с проверкой трёх библиотек в APK; секреты подписи необязательны (без них debug-ключ); отдельный workflow документации MkDocs.
